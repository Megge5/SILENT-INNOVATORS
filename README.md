# 🌟 Silent Innovators

An interactive educational showcase website that highlights overlooked pioneers of technology whose contributions shaped modern computing, communication, and engineering.

This project is designed as a **modern, Apple-inspired UI experience** with smooth animations, interactive elements, and a clean storytelling structure.

---

## 🚀 Live Demo
https://Megge5.github.io/SILENT-INNOVATORS/

---

## 📌 Project Objective

The purpose of this website is to:
- Create awareness about forgotten or under-recognized innovators in technology
- Present their contributions in a visually engaging and interactive format
- Demonstrate modern frontend development skills using HTML, CSS, and JavaScript

---

## 🧠 Featured Innovators

This project showcases 8 major contributors:

- Ada Lovelace — First Computer Programmer  
- George Boole — Founder of Boolean Logic  
- Nikola Tesla — AC Power Systems Pioneer  
- Hedy Lamarr — Wireless Frequency Hopping Technology  
- Radia Perlman — Mother of Internet Protocols  
- Claude Shannon — Father of Information Theory  
- Alan Turing — Father of Theoretical Computer Science  
- Jagadish Chandra Bose — Wireless Communication Pioneer

## ✨ Key Features

- 🎨 Apple-style minimal UI design
- 🧊 3D hover effect cards
- 🌓 Dark / Light mode toggle
- 📱 Fully responsive design (mobile + desktop)
- 📌 Interactive timeline section
- 🧠 Educational “Did You Know?” facts section
- ❓ Mini JavaScript quiz
- 🪟 Modal popup with detailed innovator profiles
- ⚡ Smooth animations and transitions
- 🧭 Responsive navigation menu

## 🛠️ Tech Stack

- HTML5

## 🌐 Deployment

This project is deployed using **GitHub Pages**.

To deploy your own version:
1. Push code to GitHub repository
2. Go to Settings → Pages
3. Select branch: `main`
4. Click Save
5. Your site will be live in a few minutes
